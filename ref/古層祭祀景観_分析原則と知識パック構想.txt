以下のように、既存の「古層祭祀景観」の考え方に、風土記・古伝承を地域別の知識パックとして蓄積し、史料の性格と確度を分離して比較する仕組みを加えた Markdown にまとめます。

# 古層祭祀景観 — 分析原則と知識パック構想

## 1. 基本理念

古層祭祀景観とは、現在の神社や祭神の構成だけから過去を説明するのではなく、土地・祭祀・神話・考古資料・政治・交通・氏族の関係を重ね合わせ、地域に残された古い信仰と社会構造の痕跡を読み解くための分析枠組みである。

神社は、単なる宗教施設ではない。土地の記憶、自然への畏怖、集団の祭祀、政治的な権威、交通上の要所など、異なる時代の要素が重なって成立している可能性がある。

そのため、現在の祭神や由緒をそのまま古代へ投影せず、**何が、いつ、どの場所で確認できるのか**を分解して考察する。

## 2. 分析の基本原則

### 2.1 土地と祭祀の関係を起点にする

以下の要素を相互に関連づけて分析する。

- **土地・自然環境**：山、岩、海、岬、河川、湧水、平野、峠、地名
- **祭祀**：自然物への祭祀、神籬、磐座、祭祀遺跡、神社の立地
- **神話・神名**：祭神の性格、神話上の役割、神名の由来、地域伝承
- **考古資料**：古墳、遺跡、出土品、祭祀遺物、集落の変遷
- **政治・社会**：氏族、地域勢力、王権、国家祭祀、神社制度
- **交通・交流**：海上交通、港、島、峠、河川交通、交易路
- **史料・伝承**：風土記、記紀、古文書、社伝、地誌、口承伝承

単一の要素だけで古層を判定せず、複数の独立した証拠がどこまで整合するかを確認する。

### 2.2 祭神の由緒と祭祀の歴史を分離する

特に重要なのは、次の二つを混同しないことである。

1. ある神が古代から存在した、または信仰されていたと考えられること
2. その神が現在の神社の場所で、古代から祀られていたと確認できること

両者は別の命題であり、前者が成立しても後者が自動的に成立するわけではない。

現在の祭神が古代の神名を持つ場合でも、祭祀の開始時期、場所の移動、合祀、祭神の変更などを別々に検討する。

### 2.3 後世の再編を古代に遡及させない

以下の歴史的変化を考慮する。

- 神仏習合とその解体
- 神社の合祀、遷座、祭神の変更
- 氏族や地域勢力による祭祀の再編
- 王権・国家による神話や祭祀の体系化
- 中世・近世の縁起や社伝の成立
- 明治期以降の神社制度・祭神整理

現在の神社の姿は、複数の時代の再編を経た結果である可能性がある。現状から古代の姿を推定するときは、各要素の成立時期を確認する。

### 2.4 神話を重要な分析対象として扱う

神話は、単なる史実の記録でも、単なる創作でもない。

神話には、自然観、祭祀の意味、地域間の関係、権威の正当化、政治秩序の形成などが表現されている可能性がある。

そのため、神話を史実として直接採用することも、史実でないという理由だけで切り捨てることも避ける。

**神話が何を語るか、いつ記録されたか、どのような社会的機能を持ったか**を分けて検討する。

## 3. 史料の種類と扱い

### 3.1 同じ「古い伝承」として一括しない

地域の伝承資料には、成立時期も性格も異なるものが含まれる。

| 史料の種類 | 主な価値 | 注意点 |
|---|---|---|
| 『古事記』『日本書紀』 | 王権が編纂した神話・系譜・政治的記憶 | 編纂目的や政治的背景を考慮する |
| 古代の風土記 | 地名、土地の由来、神話、地域社会の記録 | 成立年代、現存状況、記述の性格に差がある |
| 考古資料・発掘報告 | 遺構、遺物、年代、活動の痕跡 | 出土状況と解釈の根拠を確認する |
| 古代・中世の文書 | 神社、氏族、土地、祭祀の具体的記録 | 文書の成立年代、伝来、後世の写本を確認する |
| 神社の社伝・縁起 | 神社側に伝わる由緒や自己認識 | 記述が成立した時期と対象時代を分ける |
| 地方の古伝承・古史古伝 | 地域独自の歴史観、伝承、思想 | 伝承の存在と、伝承内容の史実性を分ける |
| 近代以降の郷土史・研究書 | 伝承の収集、地域史の整理、解釈 | 依拠する原資料と引用経路を確認する |

古代の風土記と、近代以降に成立・流布した古史古伝は、名称や内容が似ていても、史料としての性格が異なる。

### 3.2 風土記と古伝承を別の知識層として扱う

古代の風土記は、古代社会の地名・神話・土地認識を知るための重要な史料である。一方、後世の古伝承や古史古伝は、それ自体が地域の歴史認識や思想の形成を研究する材料になり得る。

ただし、古史古伝に書かれた古代王統や神々の系譜を、そのまま古代史の事実として扱ってはならない。

例えば、飛騨に関する『鞍ヶ根風土記』とされる伝承を調べる場合は、少なくとも次を区別する。

- その文献・伝承が実際に何を記述しているか
- いつ、誰によって記録・公刊されたか
- 伝承の原資料や口承の採録過程を確認できるか
- 記述された系譜や出来事を裏づける独立した証拠があるか
- 他の神話・系譜・古史古伝との類似が、何を意味するか

伝承の内容が興味深いことと、その内容が古代の史実であることは別問題である。

## 4. 証拠の確度を明示する

知識パックに収録する情報は、記述の種類と確度を明示する。

### A：独立した根拠によって確認できる事実

考古資料、同時代またはそれに近い史料、年代の確かな文書などによって裏づけられる事項。

例：
- 特定の時期に遺跡が存在したこと
- 文献に特定の地名や神名が記載されていること
- 発掘によって確認された遺構や遺物

### B：史料・伝承に記されている事実

文献や伝承に何が書かれているかについての事実。記述内容そのものが史実であると認定されたことを意味しない。

例：
- 風土記に特定の神話が記されている
- 社伝が神社の創建を特定の時代に位置づけている
- 古史古伝が独自の王統を記載している

### C：根拠を伴う仮説・解釈

複数の資料や地理的条件などから導かれた解釈。根拠、反証、代替仮説を併記する。

例：
- 港湾立地と祭祀の関係
- 特定の氏族と神社の関係
- 神話上の地名と実際の地域との対応

### D：未検証の伝承・主張

根拠が限られる口承、出典が追えない記述、独立した裏づけがない系譜や歴史主張など。

例：
- 古代の統一王朝に関する伝承
- 後世に記録された超古代の系譜
- 出典や採録過程が不明な古代祭祀の由緒

この分類は、資料の価値を一律に順位づけするものではない。Bの資料は伝承史の研究では重要であり、Dの資料も近代の思想史や地域の自己認識を考えるうえで価値を持ち得る。

**何についての証拠なのか**を明確にすることが重要である。

## 5. 古層祭祀景観の知識パック構想

### 5.1 目的

古層祭祀景観の調査を、個別の神社の由緒調べで終わらせず、地域・史料・祭祀・政治・交通の情報を再利用可能な単位で蓄積する。

知識パックは、地域の歴史を一つの物語にまとめるためのものではない。異なる史料や解釈を比較し、どこまで分かっていて、どこからが仮説なのかを追跡できるようにするためのものである。

### 5.2 知識パックの種類

#### ① 史料パック

特定の史料を中心に、その成立年代、内容、現存状況、研究上の論点を整理する。

例：
- 『出雲国風土記』
- 『播磨国風土記』
- 『常陸国風土記』
- 『肥前国風土記』
- 『豊後国風土記』

これらは現存状況や伝来の事情が同じではないため、各史料の成立・残存状況を個別に記録する。

#### ② 地域パック

一つの地域を対象に、地名、祭祀地点、遺跡、神社、氏族、交通、政治史を統合する。

候補：
- 出雲
- 筑紫・北部九州
- 飛騨
- 熊野
- 富士周辺
- 津軽・東北北部

地域を一括して単一の文化圏とみなすのではなく、内部の差異や時代ごとの変化も記録する。

#### ③ 系譜・伝承パック

神々、人物、氏族、王統に関する系譜や伝承を収録する。

収録時には次を区別する。

- 系譜が記載された史料
- その史料の成立年代
- 系譜の構造と他資料との対応
- 独立した裏づけの有無
- 後世の編集・接続・同定の可能性

異なる文献の系譜を、同じ人物や神を指すものとして安易に統合しない。

#### ④ 祭祀景観パック

複数の神社・祭祀地点・遺跡を、土地と地域社会の関係から分析する。

主な項目：
- 山・岩・海・河川などの自然環境
- 祭祀地点と集落・古墳・港湾の位置関係
- 地名や神名の分布
- 交通経路と地域間交流
- 祭祀の変化と神社制度の変遷
- 史料間の一致点・不一致点

地形は重要な分析要素の一つだが、すべての調査に必須の説明原理とはしない。史料、考古資料、神話、政治史など、問いに応じて適切な要素を組み合わせる。

## 6. 知識パックの共通データ項目

各パックでは、可能な限り次の情報を共通形式で記録する。

| 項目 | 記録内容 |
|---|---|
| ID | 資料・地点・人物・祭祀などを識別する一意のID |
| 名称 | 神社名、遺跡名、地名、史料名、神名など |
| 対象地域 | 現在の行政区分と歴史的な地域名 |
| 対象年代 | 記述・遺構・祭祀など、それぞれの対象時期 |
| 根拠資料 | 文献名、発掘報告、出土資料、論文など |
| 史料の成立年代 | 対象となる出来事の年代とは分けて記録 |
| 原文・記述 | 可能な限り原文、所在、該当箇所を記録 |
| 事実と解釈 | 資料に明記された内容と、そこからの推論を分離 |
| 関連対象 | 神社、祭神、人物、氏族、遺跡、地名など |
| 政治・交通との関係 | 地域勢力、交易、港、峠、交通路など |
| 確度区分 | A・B・C・Dと、その判定理由 |
| 反証・異説 | 対立する解釈、矛盾する資料、代替仮説 |
| 未解決事項 | 追加調査が必要な点 |
| 出典追跡情報 | 書名、著者、刊行年、ページ、URLなど |

「対象年代」と「史料の成立年代」は必ず別項目にする。後世の文献が古代について記述している場合、この区別が分析の根幹となる。

## 7. 地域間比較の方法

知識パックを作る目的の一つは、地域ごとの祭祀や神話を比較することである。

ただし、神名や神話が似ているだけで、同一の起源や直接的な伝播を結論づけない。

比較では、次の点を検討する。

1. **共通性**：神名、祭祀形態、地名、伝承構造に何が共通するか
2. **差異**：地域ごとにどのような違いがあるか
3. **年代**：各要素の成立・記録時期は比較可能か
4. **接触可能性**：海上交通、交易、移住、政治関係などの経路があったか
5. **独立性**：共通する情報が独立した伝承なのか、後世の文献や制度を介して共有されたのか
6. **代替説明**：偶然の類似、共通の文化基盤、後世の再編などで説明できないか

この方法により、地域間のつながりを検討しながら、無理に単一の起源へ収束させることを避ける。

## 8. 初期の構築計画

### 第1段階：出雲の史料パック

『出雲国風土記』を起点に、記載された地名、神々、土地の由来、地域社会の情報を整理する。

目的：
- 古代風土記を基準となる史料パックとして整備する
- 文献に書かれたことと、考古学などで確認できることを比較する
- 神話・地名・祭祀・政治的背景の接点を整理する

### 第2段階：筑紫・北部九州の地域パック

福岡を中心とする北部九州を対象に、神社、祭祀地点、古墳、地名、海上交通、氏族、記紀・風土記などの史料を統合する。

目的：
- 地域内の祭祀地点を相互に比較する
- 神名や神話の類似だけでなく、立地・年代・考古資料を含めて分析する
- 国家祭祀や後世の神社制度による再編と、地域に根ざした祭祀の痕跡を区別する

### 第3段階：飛騨の古伝承パック

『鞍ヶ根風土記』とされる資料など、飛騨に関する古伝承を対象に、伝承内容と成立・伝来の経緯を整理する。

目的：
- 古伝承の記述内容を正確に把握する
- 文献の成立時期、採録過程、引用関係を確認する
- 古代史の主張と、近代以降の伝承・思想史を区別する
- 独立した考古資料・文献資料との照合可能性を評価する

このパックは、古代史の基準資料を作るものではなく、**異なる性格の史料をどのように評価し、扱うかを検証するケーススタディ**として位置づける。

## 9. 運用上のルール

- 史料に記されている内容と、歴史的事実として確認できる内容を区別する。
- 神社の創建伝承を、そのまま祭祀開始の証拠としない。
- 現在の祭神と古代の祭祀対象が同一であると、根拠なく仮定しない。
- 神話・系譜・地名の類似を、直接的な系譜関係や伝播の証拠としない。
- 後世の社伝や古伝承も排除せず、成立時期と研究対象としての価値を明示する。
- 仮説には根拠、反証、代替説明を併記する。
- 不明な点は不明と記録し、推測によって空欄を埋めない。
- 新しい資料が見つかった場合、従来の解釈を更新できる構造にする。

## 10. 最終的な目標

古層祭祀景観の知識基盤は、神社や神話の由緒を一つの正解にまとめるためのものではない。

土地に残る祭祀の痕跡、古代文献の記述、考古学的事実、政治的な再編、地域に伝わる記憶を相互に照合し、**何が分かっているのか、何が推定なのか、何が伝承として存在するのか、何が未解決なのか**を明確にするためのものである。

地域ごとの知識パックを積み重ねることで、神社単体では見えにくい地域間の関係や、古代から現代までの祭祀景観の変化を比較できるようにする。

最終的には、固定された古代史の物語ではなく、新たな史料や発見によって検証・更新できる、出典追跡可能な知識体系を目指す。
