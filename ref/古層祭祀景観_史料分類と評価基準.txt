# 古層祭祀景観 — 史料分類と評価基準

## 1. 目的

古層祭祀景観の調査で扱う書物・文献を、成立年代、伝来、記述内容、歴史的な裏づけに基づいて分類する。

目的は、古い書物だけを採用したり、後世の伝承を一律に排除したりすることではない。資料ごとに何を明らかにできるのかを区別し、古代の祭祀・神話・地名・氏族・政治・交通の関係を比較検討できるようにすることである。

## 2. 基本原則

### 2.1 古代について書かれた書物と、古代に成立した書物を区別する

後世の書物が古代の出来事を記録していても、それだけで古代の史料になるわけではない。

一方、後世の編纂物に古い伝承や文書が保存されている可能性もあるため、成立年代だけで資料の価値を決めない。

### 2.2 次の3つの年代を分ける

- **作品の成立年代**：書物が成立した時期
- **現存資料の年代**：現存する写本・版本などが作られた時期
- **記述対象の年代**：書物が描いている出来事や祭祀の時期

この3つを分けることで、後世の記録を古代の同時代資料と誤認することを防ぐ。

### 2.3 資料の性格と、記述の確度を別々に評価する

古代成立の書物であっても、神話や系譜の記述がそのまま史実とは限らない。

逆に、近代に記録された伝承であっても、その時代の地域社会の歴史認識や信仰を知る資料として価値を持ち得る。

したがって、以下の二つを独立して管理する。

1. その資料は、いつ、どのように成立・伝来したのか。
2. その資料に記された個々の内容は、どの程度裏づけられるのか。

## 3. 史料の4分類

### A：古代に成立した基礎史料

古代社会に比較的近い時期に成立し、成立年代や伝来を研究できる史料。

| 書物 | 成立時期の目安 | 主な研究対象 |
|---|---|---|
| 『古事記』 | 712年 | 神話、系譜、王権の歴史認識 |
| 『日本書紀』 | 720年 | 国家による歴史編纂、神話、政治秩序 |
| 『出雲国風土記』 | 733年 | 地名、神話、土地、地域社会 |
| 『播磨国風土記』 | 8世紀前半頃 | 地名、地域伝承、土地の由来 |
| 『常陸国風土記』 | 8世紀前半頃 | 東国の地名、伝承、地域社会 |
| 『肥前国風土記』 | 8世紀前半頃 | 北部九州の地名、神話、地域伝承 |
| 『豊後国風土記』 | 8世紀前半頃 | 九州の地名、伝承、地域情報 |
| 『万葉集』 | 8世紀に編纂 | 歌、地名、信仰、古代社会の認識 |

注意点：

- 成立年代が古いことと、個々の記述が史実であることは別である。
- 国家による編纂と地域の記録では、目的や視点が異なる。
- 現存状況や写本の伝来は書物ごとに異なる。
- 風土記は一括して同じ保存状態・史料的条件にあるものとみなさない。

**古層祭祀景観での位置づけ：** 古代の神名・地名・神話・祭祀・政治的背景を検討するための基礎史料群。

### B：後世に編纂された歴史資料・伝承資料

中世・近世などに、古文書、口承、系譜、社伝、地域伝承などを記録・編集した資料。

| 資料群 | 主な内容 | 確認事項 |
|---|---|---|
| 神社の縁起・社伝 | 創建、祭神、遷座、霊験、由緒 | 成立年代、引用元、後世の改変 |
| 氏族の系図 | 祖先、神々との関係、系譜 | 成立年代、系譜の追加・接続 |
| 地方の地誌・郷土史 | 地名、寺社、地域の歴史 | 原資料、編者の解釈 |
| 氏族・神社に関する古文書 | 土地、祭祀、権利、由緒 | 文書の真正性、伝来、作成目的 |
| 『九鬼文書』とされる文書群 | 神々、系譜、神代に関する伝承 | 個々の文書の成立・伝来・真正性 |
| 『但馬故事記』 | 但馬地域の歴史・系譜に関する記述 | 現存本、成立経緯、独立した裏づけ |

注意点：

後世の資料であることは、ただちに無価値であることを意味しない。

たとえば中世の社伝は、古代の創建を直接証明できなくても、中世の人々がその神社の歴史や祭祀をどう理解していたかを示す。

**古代の事実を証明する資料としての価値と、後世の伝承史を研究する資料としての価値を分けて評価する。**

### C：古史古伝・成立や伝来に検討が必要な文献

古代の神話・王統・世界史などを独自に描く一方、成立年代、伝来、原資料、独立した裏づけについて検証を要する文献。

| 書物 | 主な特徴 | 扱い方 |
|---|---|---|
| 『ホツマツタヱ』 | 独自の文字・神話・系譜による古代史 | 成立・伝来と記述内容を分けて検討 |
| 『竹内文書』 | 独自の古代王統や世界史的主張 | 原資料、伝来、独立した裏づけを検証 |
| 『上記（ウエツフミ）』 | 独自の神話・系譜を伝える文献 | 成立年代、伝承経路、他資料との関係を検証 |
| 『宮下文書』 | 富士周辺に関する独自の古代史・系譜 | 地域伝承の形成史と古代史の主張を区別 |
| 『東日流外三郡誌』 | 東北の古代史を独自に描く文献 | 成立・伝来と歴史的な裏づけを検証 |
| 『鞍ヶ根風土記』とされる資料 | 飛騨に関する独自の系譜・古代史伝承として紹介される | 書誌、原資料、採録経緯を確認 |

注意点：

- 「古史古伝」という名称だけで、すべてを同一の文献群として扱わない。
- 文献に書かれた内容と、その内容が古代の史実であることを区別する。
- 独立した裏づけがない系譜や古代王統は、確定した歴史として採用しない。
- 古代史の証拠として採用できない場合でも、伝承史・思想史・地域の歴史認識を研究する資料になり得る。

特に『鞍ヶ根風土記』とされる資料については、題名に「風土記」とあることだけで、奈良時代の風土記と同じ性格の史料だとは判断しない。成立年代や原資料を確認できるまでは、暫定分類として扱う。

### D：現代の研究書・注釈書・発掘報告

古文献、考古資料、地理、民俗などを使って過去を分析・再構成する資料。

| 資料群 | 主な役割 |
|---|---|
| 風土記の校注・現代語訳 | 原文、異本、語句、地名の解釈 |
| 考古学の発掘報告書 | 遺構、遺物、年代、出土状況 |
| 神社史・地域史の研究書 | 祭祀の変遷、氏族、地域社会の関係 |
| 神話・宗教史の研究書 | 神話の成立、祭祀、政治的背景 |
| 歴史地理・交通史の研究 | 地名、港、峠、交通経路、地域間交流 |

注意点：

現代の研究書は古代の一次史料ではないが、資料の解釈や照合に不可欠である。

研究書の結論をそのまま採用せず、根拠となる原史料・発掘資料・研究方法に遡れるようにする。

## 4. 史料の種類と歴史的な裏づけを別々に管理する

史料の4分類は、書物の性格を示すものであり、記述内容の正しさを直接判定するものではない。

個々の記述には、別途、次の確度区分を付ける。

| 区分 | 意味 |
|---|---|
| A：独立した根拠あり | 考古資料、複数の独立した史料などで裏づけられる |
| B：記述の存在を確認 | 文献や伝承に書かれていることは確認できるが、内容の史実性は別問題 |
| C：研究上の仮説 | 根拠を伴う解釈であり、反証や代替仮説の検討が必要 |
| D：未検証の主張 | 出典や独立した裏づけが不十分な伝承・主張 |

この区分は、すべての対象を単純な信頼度ランキングに並べるためのものではない。

たとえば、ある伝承が古代の史実を証明できなくても、近世にその伝承が存在したこと自体は確かな場合がある。その場合は、対象となる命題ごとに確度を判定する。

## 5. 古層祭祀景観における運用

### 5.1 神社の祭祀史を分析する

神社について、少なくとも次の事項を区別して記録する。

- 現在の祭神
- 神社の由緒が主張する創建時期
- 祭祀の存在を確認できる最古の史料
- 現在地での祭祀が確認できる最古の史料
- 遷座・合祀・祭神変更の記録
- 関連する遺跡・古墳・自然祭祀地点
- 地域の氏族・政治・交通との関係

祭神が古代の神名を持つことだけで、その神が同じ場所で古代から祀られていたと判断しない。

### 5.2 神話・系譜を分析する

神話や系譜について、次の点を記録する。

- どの文献に記されているか
- その文献の成立年代
- 現存資料の年代と伝来
- 神話・系譜の記述内容
- 他の文献との共通点・相違点
- 独立した考古学的・文献学的裏づけ
- 後世の接続・同定・編集の可能性

異なる文献の神名や系譜が似ている場合でも、同一の起源や直接的な系譜関係を安易に結論づけない。

### 5.3 地域伝承を分析する

地域伝承は、史実性だけでなく、地域社会の歴史認識を示す資料として扱う。

たとえば飛騨に関する古伝承を調べる場合は、次の順序で確認する。

1. 文献の書誌情報と現存状況を確認する。
2. 成立年代と記録・採録の経緯を調べる。
3. 原文や引用元を確認する。
4. 記述された系譜や出来事を他の史料と照合する。
5. 独立した裏づけの有無を評価する。
6. 古代史としての主張と、後世の伝承・思想史としての価値を分ける。

## 6. 共通のデータ項目

各書物と、そこから得られる個々の記述を分けて管理する。

### 書物・史料の項目

- 史料ID
- 書名・資料名
- 史料分類（A〜D）
- 成立年代
- 現存資料の年代
- 著者・編者・採録者
- 成立・伝来の経緯
- 原本・写本・版本の情報
- 依拠する先行資料
- 書誌情報・参考文献
- 未解決の書誌的問題

### 個々の記述の項目

- 記述ID
- 対象となる神・人物・祭祀・地名・遺跡
- 記述内容または原文
- 出典箇所
- 記述対象の年代
- 確度区分（A〜D）
- 根拠と推論の区別
- 関連する考古資料・他文献
- 反証・異説・代替仮説
- 未解決事項

これにより、一冊の書物を一律に「信頼できる／できない」と判定するのではなく、記述ごとに評価できる。

## 7. 初期の基準資料セット

古層祭祀景観の知識基盤を構築する際は、次の順序で資料を整備する。

### 第1段階：古代の基礎史料

- 『古事記』
- 『日本書紀』
- 『出雲国風土記』
- 必要に応じて他の現存風土記
- 考古学の発掘報告書

目的：古代の神話、地名、祭祀、政治的背景を検討するための基準を作る。

### 第2段階：地域別の伝承・文書

- 神社の社伝・縁起
- 氏族の系図
- 地域の古文書・地誌
- 中世・近世の神社史・郷土史

目的：地域の祭祀や歴史認識が、時代ごとにどう変化したかを調べる。

### 第3段階：古史古伝・独自の古代史伝承

- 『ホツマツタヱ』
- 『竹内文書』
- 『上記（ウエツフミ）』
- 『宮下文書』
- 『東日流外三郡誌』
- 『鞍ヶ根風土記』とされる資料

目的：成立・伝来を検証し、古代史の主張と後世の伝承・思想史を分けて扱う。

### 第4段階：現代の研究成果

- 文献学・古代史の研究書
- 考古学の発掘報告書
- 神社史・宗教史・民俗学の研究
- 歴史地理・交通史の研究

目的：原史料を照合し、解釈の根拠、反証、未解決点を整理する。

## 8. 最終方針

古層祭祀景観の史料整理では、書物を「古いから正しい」「新しいから誤り」と単純に分類しない。

重要なのは、次の区別を維持することである。

1. **史料がいつ成立したか**
2. **現存資料がいつのものか**
3. **何が記述されているか**
4. **記述内容がどの程度裏づけられるか**
5. **その資料が歴史研究のどの領域で価値を持つか**

この仕組みによって、古代の基礎史料、後世の編纂物、地域の古伝承、古史古伝、現代の研究成果を同じ知識基盤の中で比較できる。

目指すのは、伝承を無条件に採用することでも排除することでもなく、出典と根拠を追跡しながら、古層祭祀景観の理解を継続的に検証・更新できる体系である。
