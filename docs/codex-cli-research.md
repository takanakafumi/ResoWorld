# Codex CLIによる公開情報調査

## 目的

ResoWorldの「次に見る候補」を、OpenAI APIをアプリへ直接組み込まずに公開情報で補強するためのPoCです。ローカルにインストール済みのCodex CLIと、その既存ログイン情報を利用します。

Codex CLIはローカルで起動しますが、モデル処理とWeb検索はローカルLLMではありません。Codexのサービスへ最小化した調査ブリーフが送られます。

## 実行フロー

1. レビュー画面で探索候補を選ぶ。
2. Codexへ渡す最小ブリーフを確認する。
3. 公開Web検索への明示同意をチェックする。
4. アプリのサーバーが`codex exec`を1件だけ起動する。
5. 出典付き候補と人が確認すべき点を画面へ一時表示する。
6. 人が確認するまでAtlasへは反映しない。

## 境界

- プロンプトはサーバー側で探索候補から再生成し、ブラウザーから自由文を受け取らない。
- 旅行記本文、Evidence引用、Claim ID、訪問地点一覧、ローカルファイルパスを渡さない。
- 空の一時ディレクトリを作業場所にし、リポジトリや非公開データをCodexの作業領域にしない。
- `--ephemeral`、`--sandbox read-only`、`--ignore-user-config`を使う。
- JSON Schemaで候補・出典・人の確認事項を検証する。
- 同時実行は1件、既定タイムアウトは180秒。
- 一時ファイルは実行後に削除し、結果を自動保存しない。

## 設定

`.env.local`で次を設定します。

```dotenv
RESOWORLD_CODEX_CLI_ENABLED=true
RESOWORLD_CODEX_CLI_PATH=codex
RESOWORLD_CODEX_CLI_TIMEOUT_MS=180000
```

設定変更後はNext.js開発サーバーを再起動します。Codex CLI自体のログインが切れている場合は、ターミナルでCodexへ再ログインしてください。

## 現段階で行わないこと

- 調査結果のAtlasへの自動採用
- 複数ジョブのキュー実行
- 旅行記全文を使った検索
- OpenAI APIへの自動フォールバック
