# ADR-0017: TOPICの抽象度基準と地域性・物語・構造の設計原則

- Status: Accepted
- Date: 2026-10-07

## Context

LENS配下のTOPIC一覧において、以下の構造的歪みと設計上の迷いが生じていた。

1. **抽象度（スコープ・粒度）の不揃い**:
   - 律令国家全体の制度（式内名神大社制度、古代官道網）という「マクロ」なTOPICの隣に、
   - 単一の境内・小社変遷（宮島摂末社の史的変遷、沖ノ島祭祀遺跡の変遷）という「ミクロ」なTOPICが同列に並んでいた。
2. **「旅行の都合」がナレッジTOPICへ侵食**:
   - 初期PoCの個別旅行記の作成過程で、「宗像・宇佐・国東・鞆の浦・広島を訪問から生まれた比較」や「邪馬台国探索で訪れた神社」のように、**ユーザーがたまたま旅行でそこへ行ったからという偶発的都合**が普遍ナレッジのTOPIC名や定義に混入していた。
   - 国家制度であるはずの「諸国一宮」や「古代官道」に、訪問先の都合で「西国」「西海道」という限定詞が付着していた。
3. **物語型と構造型の二項対立の限界**:
   - 物語型（通時・出来事・行程）と構造型（共時・制度・空間網）を排他的なカテゴリ分けとして捉えようとすると、「出雲国譲りと大国主系譜」や「白村江後の古代国防・山城」のように、**歴史的出来事（物語）が空間・制度（構造）を生み出している優れたテーマ**を不当に歪めたり過剰分解することになる。

## Decision

TOPICの設計および分割・統合について、以下の原則を正本とする。

### 1. TOPIC成立根拠の2大系統

TOPICは以下の2系統のいずれかに属するものとして定義し、「旅行の都合による地域性の混入」を排除する。

| 系統 | 前提と成立根拠 | TOPIC名の規律 | 実例 |
| :--- | :--- | :--- | :--- |
| **① 風土・史跡固有型<br>(Locality-Grounding)** | ナレッジパックそのものが、特定の聖域・地域・藩の風土や歴史を対象とする。 | **その土地の固有名称（山・島・地域名）を堂々と冠する。** | ・宗像・沖ノ島の国家祭祀変遷と三宮景観<br>・厳島・弥山の神域景観と社殿・登拝路<br>・出雲国譲り神話と大国主系譜<br>・長州藩の政治体制と近代化への道 |
| **② 普遍テーマ・制度・通史型<br>(Structural & Thematic)** | ナレッジパックが、神話体系、宗教史、国家制度、社会構造などを対象とする。 | **客観的・学術的なテーマ名とする。旅行の都合による限定詞（「西国」「訪問した神社」等）は一切付けない。** | ・延喜式神名帳と式内名神大社制度<br>・令制国体制と諸国一宮の祭祀網<br>・古代官道と七道駅路ネットワーク<br>・海洋神話と海人族三系統の航路掌握<br>・原初祭祀景観と巨石・海浜の自然崇拝<br>・神仏習合と山岳修験の重層 |

- 普遍テーマ型において、ユーザーが訪れたスポット（例: 宇佐、国東、宗像、鞆の浦等）は、**その普遍テーマに接続する「具体例・実証地（インスタンス）」としてAtlas上にプロットされる**。TOPIC定義自体を特定地域の寄せ集めにしない。

### 2. 適切な抽象度の基準軸：メゾ（広域テーマ・回廊スケール）

TOPICの粒度は、以下の基準に収束させる。

> **「旅行者が2〜5箇所の関連スポットを巡って、『なるほど、こういう繋がりか！』と腑に落ちる広域テーマ（メゾ・回廊スケール）」**

- 単一境内・単一遺跡に閉じたミクロ事象（境内の末社変遷、単一遺跡の環濠）は、地域固有テーマの中の1ノード（構成要素）へ内包・統合する。
- 抽象的すぎる哲学概念（アニミズム、多神・一神等の比較論）は、日本列島の具体的な祭祀空間（巨石・岩礁等の自然物信仰）へ接地させる。

### 3. 物語と構造の「多面的属性（タグ）」化

物語と構造は排他的な2分法（カテゴリ）ではなく、TOPICが併せ持つ特性（属性）として定義する。

- **📖 物語（Narrative）特性**: 時間の不可逆な進行、出発地から目的地への行程、神話・歴史の出来事・ドラマ。
- **🏛️ 構造（Structural）特性**: 同時代における関係網、空間配置、制度・格付け、対比・重層。
- **両方（Narrative × Structural）**: 出来事（物語）が空間・制度（構造）を規定しているテーマ（出雲国譲りと系譜、白村江後の古代国防、平氏政権と厳島社殿、松下村塾と志士行動網など）。

### 4. 地名ではなく「固有の歴史・文化現象ワード」で表現する規律

風土・史跡固有型において、単なる行政地名や河川名（「朝倉」「筑後川流域」など）でお茶を濁さない。
その土地が体現している**「固有の歴史・文化現象ワード（歴史的実体）」**を明示する。

- ❌ `筑後川流域の弥生拠点集落構造` ➔ ⭕ **`低湿地多重環濠と内陸拠点集落の構造`**（吉野ヶ里等の丘陵立地と対比される、低湿地土木・三重環濠・祭殿という考古学的固有性）
- ❌ `筑紫中部の古層神話と大己貴祭祀` ➔ ⭕ **`出雲国譲り神話と大己貴・国津神系譜`** への完全統合（朝倉・三輪・出雲の大己貴祭祀を分断せず、西日本に広がる国津神広域ネットワークとして一本化）

### 5. 水平のLENS（探索視座）と垂直の通史基盤（時代地層）の完全分離

「古代祭祀の変遷」や「自然崇拝・アニミズム」など、全スポットを貫く時代推移・基礎概念は、**水平に切り替えるLENSのTOPICボタンから除外する**。

- **LENS（水平軸）**: スポット群を特定の制度・空間・人物ネットワークで見直す探索フィルター。
- **通史・時代地層（垂直軸）**: 原初自然崇拝 ➔ 古代国家祭祀 ➔ 律令官撰 ➔ 神仏習合・修験 ➔ 近代という全スポット共通の垂直の時代地層。
- **操作の分離**: 通史・時代地層は、LENS内のボタンではなく、独立した操作口（`[ 📜 通史・時代地層 ]`）として提供し、いつでも通史変遷と概念解説を参照できるようにする。

### 6. 2階層構造（LENS ➔ TOPIC）の維持と「単一焦点 (Single Focus)」の規律

TOPICの表現が似通うことによる混乱を防ぎつつ、UIの過剰複雑化を避けるため、以下の規律を正本とする。

1. **3階層化（LENS ➔ 中カテゴリ ➔ TOPIC）の排除**:
   - フォルダ展開やアコーディオン等の選択階層を増やさず、`LENS ➔ TOPIC` のワンクリック操作（2階層）を厳格に維持する。
2. **特性（Feature・形式）と焦点（Focus・主題）の直交分離**:
   - **特性（Feature）**: 表現形式（`narrative` / `structural`）。複数可。
   - **焦点（Focus）**: TOPICが歴史・文化のどこにスポットライトを当てているかという**存在意義・主題**。**必ず単一（1つのみ）**とする。
   - 例: `神統譜`（誓約と皇統）、`神域空間`（沖ノ島・三宮配置）、`国家制度`（延喜式神名帳）、`宗教思想`（神仏習合・八幡大菩薩）。
3. **将来の再編・統合判定基準としての活用**:
   - 焦点が単一に洗練されていることにより、「同じ焦点を持つTOPIC群」は将来的に統合・再編の検討対象として客観的に特定できる。

## Consequences

- 宗教LENSをはじめとする初期PoCの過剰分割・局所重複、および抽象的な教科書概念がLENSから一掃され、LENS内のTOPICが骨太なメゾ歴史テーマ（5〜7個）へ引き締まる。
- 旅行記の追加によって「新しい旅行先」が増えても、地名に引きずられず、固有の歴史現象ワードで表現される。
- ユーザーは「水平の探索（LENS）」と「垂直の時代推移（通史・時代地層）」を混同せず、極めて直感的に世界の解像度を上げられるようになる。
