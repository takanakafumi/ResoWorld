# ADR-0010: トップレベルLENSを五つに絞り、時代を共通軸にする

- Status: Accepted
- Date: 2026-09-10

## Context

PoCでは「地形・聖域」「時代」を含む八つの入口が並んだ。宗教や政治・社会は複数Topicと固有の図法を持つ一方、地形・聖域と時代は該当Connectionを選ぶだけで、独立LENSとしての体験を持っていなかった。旅行記ごとに入口を増やすと、接続判断とUIの双方が複雑になる。

ただし、近い分野を少数へ機械的に統合することも避ける。神の系譜と宗教構造、人物関係と政治制度は、ユーザーの問いと適した図法が異なる。

## Decision

訪問マップとは別に、トップレベルLENSの基本集合を次の五つとする。

1. 神・系譜
2. 宗教
3. ルート
4. 政治・社会
5. 人物

時代、地形・聖域、学説差は次のように扱う。

- 時代はConnectionおよび全LENSに共通する表示・絞り込み軸とする。
- 地形はMAPとルートの文脈、聖域は宗教のTopic・比較表現とする。
- 学説差は独立入口ではなく、各TopicのViewpoint、Hypothesis、解釈比較として表示する。
- 既存のEntity、Assertion、facet、era、Knowledge Packは削除しない。入口の整理は正本データの削除を意味しない。

新規LENSは、次をすべて満たす場合だけ追加する。

1. 既存LENSとは異なる問いに答える。
2. 既存rendererでは表せない固有の図法または操作が必要である。
3. 一つの旅行先に限定されず、複数Topicで再利用できる。
4. 既存LENS内のTopic切替では発見しにくく、独立入口にする価値がある。

## Consequences

- 旅行記追加時は、まず五つの既存LENSへのTopic接続を判定する。
- 宗教・政治・人物など、内容が充実した観点の情報階層を保てる。
- 時代を各LENSへ重複実装せず、同じEra情報から一貫して切り替えられる。
- 地形・聖域のConnectionはMAPや関連LENSから引き続き選択できる。
- 将来、実例が四条件を満たした場合はADRを更新して基本集合を見直せる。
