# 0014: 外部ナレッジによる探索フロンティア接続線と次の訪問候補の可視化

- 日付: 2026-09-27
- ステータス: 承認済み (Accepted)
- 関連: `docs/visit-candidate-policy.md`, `docs/decisions/0006-unify-map-connection-projection.md`, `docs/decisions/0013-project-sacred-landscapes-through-existing-lenses.md`

## コンテキスト

ResoWorld のコア価値は、単に過去に訪れた地点をなぞる旅行記地図ではなく、**「自分の旅の記録と外部ナレッジ（史料記述・神話系譜・宗教ネットワーク）が共鳴し、まだ訪れていない次の探求地が地図上に浮かび上がる」** 体験にある。

しかし、従来の実装には以下の課題があった：
1. **未訪問地を含む接続線の遮断**:
   - `connectionTouchesSpots` や `placeMatchesSpot` において、訪問済み地点の照合が厳密（`place.aliases` が無視される等）であり、訪問地と未訪問地を跨ぐナレッジ接続（例: 宇美町を起点とする魏志倭人伝の九州説・畿内説）が除外されていた。
2. **フロンティア（未訪問候補地）の接続線の欠落**:
   - 魏志倭人伝ルートのように、すでに訪問した地点（伊都・奴・不弥など）から未訪問の地点（壱岐・対馬・金海、あるいは吉野ヶ里・奈良盆地など）へ向かう「次の訪問候補」としての接続線が地図に描画されていなかった。
3. **旅程スコープ時のLENS消失**:
   - 邪馬台国探索などの旅程を選択した際に、「ルート」LENSが選択肢から消えてしまい、該当ナレッジへアクセスしにくくなっていた。

## 決定事項

### 1. ナレッジ地点照合（placeMatchesSpot）の拡張
- `place.aliases`（別名リスト）を照合対象に含める。
  - 例: `umi` の `aliases: ["宇美町"]` が、探索スポット「宇美町」と正しく一致するようにする。
- 正規化名の一致判定において、代表的な地名接尾辞（町、市、村など）や別名を適切に解決する。

### 2. 訪問地と未訪問候補地を結ぶナレッジフロンティア線（Frontier Connections）の投影
- 外部ナレッジに含まれる地点のうち：
  - **訪問済み地点**: 鮮明な訪問スポットマーカーとして描画。
  - **未訪問地点**: `kind: "reference"` / `kind: "suggested"` として、中抜き破線リング（候補ピン）で描画。
- 接続線の描画：
  - 訪問地と未訪問地を結ぶ接続線、および未訪問地間のナレッジ構造（魏志倭人伝の記述順、九州説、畿内説）を、LENS選択時およびLINESレイヤー（🟡 LENS知識線）を通じて地図上に投影する。
  - 線のスタイル（史料記述順＝青緑、九州説＝点線、畿内説＝ゴールド点線など）を維持し、確定事実と競合仮説を視覚的に区別する。

### 3. 「ルート」LENSおよび探索旅程の統合
- 邪馬台国探索などの旅程が選択されている場合でも、「ルート」LENSが正しく選択可能となるようトピック解決の連動を確保する。
- LENS「ルート」を選択した際、右側パネルに魏志倭人伝の再認識レンズ（史料順・投馬国候補・邪馬台国比定説）が表示され、地図上にすべての関連接続線と候補地が連動してハイライトされる。

### 4. 操作UI（LINES コントロールとの調和）
- マップ右上の `LINES` コントロール（「訪問ルート」「テーマ接続」「LENS知識線」）と、`次の探索候補を表示` チェックボックスにより、ユーザーが情報過多になることなく選択的にフロンティアを表示・非表示にできる。

## 結果・利点

- ユーザーは「自分が歩いた区間」と「史料や学説が示す前後の未訪問区間」を一望でき、自然に次の旅行・探索の動機を得ることができる。
- 神話系譜や宗教ネットワークにおいても、未訪問の摂末社や奥宮、ゆかりの地がフロンティアとして自然に接続される。
