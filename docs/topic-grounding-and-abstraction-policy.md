# TOPICの抽象度基準と設計運用ガイドライン (Topic Grounding & Abstraction Policy)

## 1. 目的

ResoWorldにおいて、LENSから選択される「TOPIC」は、**「現地スポット（点）の体験を、歴史・神話・社会の文脈（線・面）へと引き上げる視座」**である。

本書は、[ADR-0017](decisions/0017-topic-grounding-and-abstraction-principles.md) に基づき、TOPICの命名、抽象度基準、地域性の扱い、および「物語型」「構造型」特性の付与に関する具体的な設計運用基準を定める。

---

## 2. TOPICの2大系統と命名規則

### 系統A: 風土・史跡固有型 (Locality-Grounding)
- **対象**: 特定の地域、島、山、聖域、藩に固有の歴史・信仰空間を扱うナレッジパック。
- **命名規則**: **単なる行政地名や河川名ではなく、その土地が体現する「固有の歴史・文化現象ワード」を明示する。**
- **抽象度の基準**: 「その地域を訪れた旅行者が、1日〜2日かけて巡る信仰・史跡空間の全体像」を捉えるサイズ。
- **好例**:
  - `沖ノ島古代国家祭祀と宗像三宮景観` (Munakata Pack)
  - `厳島・弥山の神域景観と瀬戸内海上壇` (Miyajima Pack)
  - `出雲国譲り神話と大己貴・国津神系譜` (Izumo Pack)
  - `幕末長州藩の政治体制と近代化政策` (Hagi Bakumatsu Pack)
  - `低湿地多重環濠と内陸拠点集落の構造` (Asakura Pack: 政治)
  - `大和地名一致現象と邪馬台国東遷仮説` (Asakura Pack: ルート)
- **禁止事項**: 境内の中の小さな祠の移転など、ミクロすぎる事象を独立TOPICにしない（地域テーマの1ノードへ内包する）。

### 系統B: 普遍テーマ・制度・通史型 (Structural & Thematic)
- **対象**: 国家制度、交通インフラ、海人族系統、神話体系などを扱うナレッジパック。
- **命名規則**: **客観的・学術的なテーマ名とする。個人的な旅行先の地域名（「西国」「西海道」「旅行で訪れた神社」など）は一切冠しない。**
- **抽象度の基準**: 列島規模の制度や歴史的潮流を、空間的な広がり（回廊・ネットワーク）として捉えるサイズ。
- **好例**:
  - `延喜式神名帳と古代式内名神大社ネットワーク` (Shikinaisha Pack)
  - `令制国体制と諸国一宮ネットワーク` (Ichinomiya Pack)
  - `古代官道と七道駅路ネットワーク` (Ancient Highways Pack)
  - `海洋神話と海人族三系統の航路掌握` (Marine Deities Pack)
  - `白村江後の古代国防・山城` (Ancient Defense Pack)
- **旅行記との関係**: ユーザーが訪れたスポット（宗像、宇佐、国東、鞆の浦等）は、**そのテーマの「具体例（Instance）」としてAtlas上に光る**。

## 3. 物語型（Narrative）と構造型（Structural）の特性定義

TOPICは「物語」または「構造」のいずれか一方のみに属するのではなく、**両方の特性を兼ね備えることができる**。

| 特性 | 定義 | ユーザーの問い・体験 |
| :--- | :--- | :--- |
| **📖 物語（Narrative）** | 時間の不可逆な進行、移動、因果の連鎖、ドラマ | 「次に何が起きたか？」「なぜそこへ向かったのか？」「旅のどの場面か？」 |
| **🏛️ 構造（Structural）** | 同時代における関係網、空間配置、制度・格付け、対比 | 「どういう仕組み・力関係か？」「空間・制度としてどう位置づけられているか？」 |
| **📖🏛️ 両方（Narrative × Structural）** | 歴史的出来事・神話物語が、空間配置や制度構造を生み出したテーマ | 「あの出来事によって、この場所や制度がどう形作られたのか？」 |

## 4. 2階層構造の維持と「単一焦点 (Single Focus)」の設計原則

### 4.1 なぜ3階層化（LENS ➔ 中カテゴリ ➔ TOPIC）を避けるのか
「空間・考古学」や「制度・思想」といった分類をUI上の選択階層（中カテゴリ）にしてしまうと、以下の問題が生じる：
1. **操作手数と認知負荷の増大**: LENS選択後に中カテゴリの展開・タップが必要になり、軽快なワンクリック探索が損なわれる。
2. **境界の揺らぎ**: 例えば「沖ノ島」は巨石遺構（空間・考古学）であると同時にヤマト王権の祭祀制度（国家制度）でもあるため、固定的なフォルダ分類は分類論争を生む。
3. **非対称性**: 特定のLENSだけに中カテゴリを設けると、他LENS（政治・人物・ルート）との整合性が崩れる。

したがって、UI構造としては **`LENS ➔ TOPIC` のシンプルな2階層を厳格に維持** する。

### 4.2 「特性 (Feature)」と「焦点 (Focus)」の役割分離
似たような名称（神話・祭祀・航路など）が並ぶことによる混乱を防ぎ、ユーザーが「何を見せられているのか」を一目で直感できるようにするため、TOPICに以下の2つの直交するメタデータを付与する。

| メタデータ | 問い | 選択数 | 性質と役割 |
| :--- | :--- | :---: | :--- |
| **特性 (Feature)** | どういう形式で表現されているか？ | 複数可 | **表現形式** (`narrative`: 物語の進行 / `structural`: 関係・空間構造) |
| **焦点 (Focus)** | 歴史・文化のどこにスポットライトを当てているか？ | **必ず単一 (1つのみ)** | **存在意義・主題**（例: `神統譜`, `神域空間`, `国家制度`, `宗教思想`） |

> **焦点（Focus）が単一であることの重要性**:
> - 1つのTOPICに神話も空間も制度も詰め込むと、主題が曖昧になり肥大化する。
> - 焦点を単一に純化することで、TOPICの境界線が明確になる。
> - **同じ焦点を持つTOPICは、将来的に統合・再編の検討対象（候補）として客観的に特定できる。**

## 6. 独立操作口としての「通史・時代地層 (Chronological Stratum)」

「古代祭祀の変遷」「自然崇拝・アニミズム」など、全スポットを貫く通史の地層は、LENS内のボタンではなく、画面上部に常設される **`[ 📜 通史・時代地層 ]` 操作口**から閲覧する。

### 時代地層の構成
1. **原初祭祀層**: 巨石・岩礁・海浜などの自然物信仰（アニミズム、山岳・島嶼信仰）
2. **古代国家祭祀層**: 4〜9世紀のヤマト王権・沖ノ島国家祭祀、対外交流航路の加護
3. **律令神祇層**: 延喜式神名帳、式内社制度、国司・官選祭祀体制
4. **神仏習合・修験層**: 宇佐八幡・六郷満山・厳島・弥山に見られる神仏の複合と山岳信仰
5. **中世〜近世層**: 武家政権の庇護（平氏、大内、毛利、黒田等）と社殿造営
6. **近代層**: 明治維新、神仏分離・廃仏毀釈、国家神道体制と近代社格制度
