# ResoWorld コア体験

## プロダクトの役割

ResoWorldは、次の旅行先を推薦するアプリではない。

ユーザーが過去に探索した場所、観察、疑問、仮説を大まかに取り込み、それらを時間・空間・学問分野を横断して統合する。その結果を、自分専用の「探索してきた世界」として再認識できるようにし、まだ見えていない次の接続を示唆する。

中心となる価値は次の三つである。

1. 過去の訪問を思い出せる。
2. 個別の訪問を体系として見直せる。
3. 体系の空白・対立・続きを次の探索へ変えられる。

## ユーザーとシステムの関係

探索の主語は常にユーザーである。ユーザーは不足を埋めるためではなく、自分の関心のままに場所を訪れ、見て、考える。

システムの役割は、その探索を評価したり「不足」として指摘したりすることではない。ユーザーの関心を保ったまま、背景、分類、他分野の解釈、過去の別の訪問との接続を補完する。

次の探索も命令や課題として提示しない。現在の関心と響き合いそうな場合にだけ、隣接する問いや見方を任意の示唆として添える。

表示順序は「ユーザーの関心 → システムによる統合・補完 → 任意の新しい響き」を基本とする。
## 体験の二つのモード

### 1. 世界を再認識する

ユーザーは数回のクリックで、過去の訪問を異なる学際レンズから見直せる。

代表的なレンズ：

- ルート：邪馬台国への複数の想定経路、海上交通、巡礼路、政治圏の移動
- 神話・神格：古代神の系統、性格、機能、地域差、習合
- 宗教：神道、仏教、修験、神仏習合、地域信仰の分類と接続
- 系譜：天皇系譜、氏族、神の系譜、祭祀主体の接続
- 時代：同じ場所が時代によって持った意味の変化
- 学説差：文献史学、考古学、民俗学、宗教学などの解釈差
- 政治・社会：王権、地域勢力、交易、祭祀、制度の関係
- 地形・景観：海、山、川、境界、移動経路と信仰の関係

レンズは単なるタグ絞り込みではない。地図、時間、分類、系譜、対立する解釈を組み合わせて「なぜつながるのか」を見せる。

### 2. 次の接続を探索する

次の探索は、具体的な施設名から始めない。

```text
現在の探索体系
  ↓
意外な接続・解釈差・空白
  ↓
新しい問い
  ↓
探索するテーマ・地域・時代
  ↓
補助的な具体候補
```

具体的な場所や資料は、問いを検証するための候補として最後に提示する。旅行ランキング、人気順、旅程最適化を主目的にしない。

## AIへ渡す情報

体験価値を優先し、個人情報を含まない探索内容は、単一候補ではなく探索全体の分析に利用する。

- 訪問地点名、地域、地点種別
- ユーザーの観察・問い・仮説
- Claimの要約と根拠種別
- 時代、概念、人物、神格、宗教、制度
- 現在登録されている接続と分類
- 未確定・対立・不足している情報

ユーザー名、連絡先、正確な生活行動、秘密情報などは引き続き除外する。旅行記の表現そのものが必要ない場合は、全文ではなく構造化した要約を優先する。

## AI分析の成果物

AIの一時的な回答ではなく、再利用できる分析成果として次を生成する。

- World Synthesis：探索全体の要約
- Interdisciplinary Lens：学際的な見方
- Classification：分類体系と別分類の可能性
- Route / Timeline：場所と時代の連続
- Genealogy：人物・氏族・神格の系譜
- Interpretation Comparison：学問分野・学説ごとの差
- Connection：既存地点間の新しい接続候補
- Frontier：次に調べる問い、テーマ、地域、時代

各成果物は、根拠、推論、不確実性、異説を分離する。AIが生成した分類や接続を事実として自動確定しない。

## UI原則

トップレベルでは、地図とともに「再認識レンズ」を並べる。

```text
[地図]  [ルート] [神の分類] [宗教] [系譜] [学説差] [時代]
```

レンズを選ぶと、同じ訪問記録が適した表現へ切り替わる。

- ルート → 地図上の線と時系列
- 神・宗教 → 分類ツリーと地域差
- 系譜 → 系譜図と場所への接続
- 学説差 → 同じ論点に対する解釈比較
- 時代 → 時代レイヤーと意味の変化

ユーザーは、一覧から詳細へ深く潜らなくても、2〜3回の操作で「どこへ行き、何を考え、全体のどこに位置するか」を思い出せることを目標とする。

## PoCの判定

PoCでは、次の三つが実際の探索記録で発生するかを確認する。

1. 「ここへ行ったとき、こういうことを考えていた」と思い出せる。
2. 「別々の訪問が、この体系ではこうつながるのか」と再認識できる。
3. 「この空白や解釈差を確かめるため、次はこれを見たい」と感じる。

具体的な候補の精度だけでは、コア体験の成立と判断しない。
