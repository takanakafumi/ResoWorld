# ResoWorld コア体験

## プロダクトの役割

ResoWorldは、次の旅行先を推薦するアプリではない。

ユーザーが過去に探索した場所、観察、疑問、仮説を大まかに取り込み、それらを時間・空間・学問分野を横断して統合する。その結果を、自分専用の「探索してきた世界」として再認識できるようにし、まだ見えていない次の接続を示唆する。

中心となる価値は次の三つである。

1. 過去の訪問を思い出せる。
2. 個別の訪問を体系として見直せる。
3. 体系の空白・対立・続きを次の探索へ変えられる。

## ユーザーとシステムの関係

探索の主語は常にユーザーである。ユーザーは不足を埋めるためではなく、自分の関心のままに場所を訪れ、見て、考える。

システムの役割は、その探索を評価したり「不足」として指摘したりすることではない。ユーザーの関心を保ったまま、背景、分類、他分野の解釈、過去の別の訪問との接続を補完する。

次の探索も命令や課題として提示しない。現在の関心と響き合いそうな場合にだけ、隣接する問いや見方を任意の示唆として添える。

表示順序は「ユーザーの関心 → システムによる統合・補完 → 任意の新しい響き」を基本とする。

次の候補を示すときは、分析処理の区分や番号をそのまま見せない。まず「これまでのどの訪問・関心につながるのか」、次に「そこで何が見えてくるのか」、最後に「何を手がかりに見ればよいか」を、ユーザーの言葉で説明する。不足情報、不確実性、システム内部の判断根拠は補足として折りたたみ、主役にしない。

## 体験の二つのモード

### 1. 世界を再認識する

ユーザーは数回のクリックで、過去の訪問を異なる学際レンズから見直せる。

トップレベルのLENSは、再利用できる五つの観点に絞る：

- ルート：邪馬台国への複数の想定経路、海上交通、巡礼路、政治圏の移動
- 神・系譜：古代神、天皇、氏族などの系統と継承
- 宗教：神道、仏教、修験、神仏習合、地域信仰の分類と接続
- 政治・社会：王権、地域勢力、交易、祭祀、制度の関係
- 人物：師弟、同志、対立、継承、移動の関係

時代は全LENSに共通する表示軸とする。地形・景観・聖域と学説差は独立した入口を増やさず、関係するLENSのTopic、MAPレイヤー、比較表示として扱う。

レンズは単なるタグ絞り込みではない。地図、時間、分類、系譜、対立する解釈を組み合わせて「なぜつながるのか」を見せる。

### 2. 次の接続を探索する

次の探索は、具体的な施設名から始めない。

```text
現在の探索体系
  ↓
意外な接続・解釈差・空白
  ↓
新しい問い
  ↓
探索するテーマ・地域・時代
  ↓
補助的な具体候補
```

具体的な場所や資料は、問いを検証するための候補として最後に提示する。旅行ランキング、人気順、旅程最適化を主目的にしない。

具体候補は、原則として「旅行記で行きたかったが行けなかった場所」「訪問済み地点からKnowledge上の重要な関係でつながる未訪問地」「問いを検証する資料」の順に優先する。再訪は、重要な展示・遺構・史料を見落としており、その確認が問いの判断を実質的に変える場合に限る。単なる記録不足や、もう一度感想を尋ねる目的では再訪を勧めない。

「行きたかったが行けなかった場所」は、訪問済み地点や知識上の推定候補とは別に保持する。旅行記の明示的な訪問意図を根拠とし、人が分類と位置を確認したものだけを次候補へ使う。

LENSでは、現在の構造に関係するSuggestionだけを図の直後へ再投影する。最初に問いと未確認点を示し、過去との接続理由、補助的な場所・資料候補の順に読む。関係のない既存Suggestionを件数合わせで表示しない。

## AIへ渡す情報

体験価値を優先し、個人情報を含まない探索内容は、単一候補ではなく探索全体の分析に利用する。

- 訪問地点名、地域、地点種別
- ユーザーの観察・問い・仮説
- Claimの要約と根拠種別
- 時代、概念、人物、神格、宗教、制度
- 現在登録されている接続と分類
- 未確定・対立・不足している情報

ユーザー名、連絡先、正確な生活行動、秘密情報などは引き続き除外する。旅行記の表現そのものが必要ない場合は、全文ではなく構造化した要約を優先する。

## AI分析の成果物

AIの一時的な回答ではなく、再利用できる分析成果として次を生成する。

- World Synthesis：探索全体の要約
- Interdisciplinary Lens：学際的な見方
- Classification：分類体系と別分類の可能性
- Route / Timeline：場所と時代の連続
- Genealogy：人物・氏族・神格の系譜
- Interpretation Comparison：学問分野・学説ごとの差
- Connection：既存地点間の新しい接続候補
- Frontier：次に調べる問い、テーマ、地域、時代

各成果物は、根拠、推論、不確実性、異説を分離する。AIが生成した分類や接続を事実として自動確定しない。

## UI原則

トップレベルの操作は「探索範囲を選ぶ」「LENSで構造化する」の二段階とする。探索範囲は分析材料、LENSは見方であり、旅横断比較を第三の独立機能にしない。

```text
[すべての旅 / 個別Journey] → [神・系譜 / 宗教 / ルート / 政治・社会 / 人物]
                                      ↓
                              MAP・関係図・根拠
```

`すべての旅`でLENSを選ぶことが旅をまたいだ再認識であり、個別Journeyで同じLENSを選ぶことが一つの旅の再認識である。MAPはこの二つの選択結果を地理上へ投影する。

トップレベルでは、地図とともに「再認識レンズ」を並べる。

```text
[訪問マップ] [神・系譜] [宗教] [ルート] [政治・社会] [人物]
       └── 共通軸: 時代 / 学説・解釈 / 根拠の種類
```

レンズを選ぶと、同じ訪問記録が適した表現へ切り替わる。

- ルート → 地図上の線と時系列
- 神・系譜 → 系譜図と場所への接続
- 宗教 → 分類、習合、祭祀空間と地域差
- 政治・社会 → 制度、権力、外交、社会構造
- 人物 → 人物ネットワークと移動
- 共通の時代軸 → 選択中の関係が時代によって持つ意味の変化

ユーザーは、一覧から詳細へ深く潜らなくても、2〜3回の操作で「どこへ行き、何を考え、全体のどこに位置するか」を思い出せることを目標とする。

詳細な責務と将来の複数Journey選択方針は[ADR-0011](./decisions/0011-separate-exploration-scope-from-lens.md)に従う。

## PoCの判定

PoCでは、次の三つが実際の探索記録で発生するかを確認する。

1. 「ここへ行ったとき、こういうことを考えていた」と思い出せる。
2. 「別々の訪問が、この体系ではこうつながるのか」と再認識できる。
3. 「この空白や解釈差を確かめるため、次はこれを見たい」と感じる。

具体的な候補の精度だけでは、コア体験の成立と判断しない。
